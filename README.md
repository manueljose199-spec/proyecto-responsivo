## Descripción
Este proyecto es una pagina básica relacionada con temas de ciberseguridad esta construida en **HTML** **CSS** **JavaScript** , incluye una estructura simple, un botón interactivo toggle y componentes que sirven para que el proecto pueda ser escalable

*Estructira semántica en HTMl
*Gestión con git y Github
*Publicacón en Github Pages
*Documentación en README

## contenido del sitio

**Inicio**
**Amenazas**
**Consejos**

**Footer**

El diseño incluye imágenes, favicon y botones para el modo oscuro y las cookies
